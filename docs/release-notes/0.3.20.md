# Pace 0.3.20

This release turns Pace into a broader local automation product and gives its
everyday Mac interface a complete visual overhaul.

## What’s new

- Ask for automations naturally instead of memorizing command phrases.
- Browse a typed local catalog covering system controls, calendars, reminders,
  Finder, Notes, Mail, Things, Shortcuts, windows, timers, and reusable routines.
- Teach Pace new programmable automations in natural language, with validation
  and approval before generated code can run.
- Use the redesigned Living Notch, quick panel, onboarding journey, and Command
  Center as one connected native macOS interface.
- See the current action, clarification, result, or recovery message directly
  in the notch; idle state returns to the Pace identity.
- Follow the animated Pace arrow during voice input, with local/off-device color
  boundaries and Reduced Motion support.

## Reliability

- Expanded intent-routing, automation-catalog, programmable-skill, shortcut,
  native-interface, and end-to-end test coverage.
- Screen-activity indicators now remain below the Living Notch instead of
  drawing over it.
- Removed the legacy recipe layer in favor of one typed automation catalog.
