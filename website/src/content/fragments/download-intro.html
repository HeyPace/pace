Unzip the download and move Pace to Applications. The current preview is ad-hoc signed and not notarized, so macOS may block the first launch. If you choose to run this preview, first try opening Pace, then go to System Settings → Privacy & Security and use Open Anyway for Pace under Security. Confirm the per-app approval when macOS asks.

Updates itself. Once Pace is running, it checks the appcast feed every hour and installs new versions automatically via Sparkle. You won't need to come back to this page.
