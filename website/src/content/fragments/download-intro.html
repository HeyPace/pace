Open the disk image and drag Pace into Applications. The current public release is text-first. Start with a read-only text request; voice accuracy and hotkey/microphone acceptance remain unverified. See the 0.3.20 release notes for the tested scope and remaining limits.

Updates itself. Once Pace is running, it checks the appcast feed for updates through Sparkle and prompts you to relaunch when an update is ready.
