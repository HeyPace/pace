Open the disk image and drag Pace into Applications. The current preview is text-first. Voice input and the hotkey are experimental. Start with a read-only text request. See the 0.3.20 release notes for the tested scope and remaining limits.

Looking for Right Option, interactive diagrams, or Add a Power? These are available in the 0.3.21 development source. The disk image on this page is the public preview.

Updates itself. Once Pace is running, it checks the appcast feed for updates through Sparkle and prompts you to relaunch when an update is ready.
