After you download

Three steps, then it's in your menu bar.

1. Install the disk image. Open Pace-{{version}}.dmg and drag Pace.app into Applications. Eject the disk image after copying.

2. Open it. Double-click Pace.app. Review the macOS opening prompt. If it blocks the app, use the per-app guidance linked below after verifying the download source. Once Pace opens, review its Microphone, Screen Recording, and Accessibility requests for voice, screen context, and approved actions.

3. Try a read-only text request. Open Pace's text input and ask it to explain a non-sensitive sentence on screen. Enable Read My Screen only if you want screen context, and choose your local or explicitly consented external planner. Verify the answer and that the document stayed unchanged. Voice and hotkey acceptance are not part of the public release's verified scope.

Follow Apple's current opening instructions if macOS prevents the app from opening. Verify that the download came from the official release before choosing a per-app exception. Keep macOS security protections enabled.
