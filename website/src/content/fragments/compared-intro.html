The field

Mac AI agents that see your screen and run tasks.

A screen-aware Mac agent combines a way to observe the current interface, a reasoning model, permitted actions, and a visible safety boundary. Similar demos can hide sharp differences in where screenshots go, whether inference is local, whether the agent waits for a prompt or watches continuously, and whether actions need approval.

How to choose a screen-aware Mac agent

  1. Follow the data path. A local app can still send screenshots, transcripts, or prompts to a provider API.
  2. Separate observation from action. Region capture, full-screen capture, and the Accessibility tree expose different data and permissions.
  3. Check the control model. Push-to-talk, hotword, proactive watching, scheduled work, and remote commands have different interruption and safety tradeoffs.
  4. Inspect approval and recovery. Look for action previews, permission tiers, audit records, undo, and a reliable stop path.
  5. Check distribution reality. License, signed releases, supported macOS versions, API-key requirements, and update paths matter beyond the demo.

The field splits three ways. Cloud agents round-trip every turn through someone else's servers. Hybrid ones default local but let you opt into cloud. On-device ones — the cluster Pace lives in — never leave your machine.
