Auto-update

You only download from this page once.

Pace uses Sparkle — the same auto-updater most indie Mac apps use. Once it's installed, Pace checks an appcast feed every hour. When a new version ships, it downloads, verifies the EdDSA update signature, and prompts you to relaunch. This protects Sparkle updates; it does not make the current app Developer ID signed or Apple-notarized.

If you ever want to check manually: Settings → General → "Check for updates…"
