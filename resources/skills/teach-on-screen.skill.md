## Steps

1. Identify the topic in the current request or an explicit follow-up. If the user only invokes this skill by name, ask what they want to learn. For a screen-based question, read fresh permitted screen context before explaining it.
2. Show a useful visual early using the available teaching or image tools. Use an interactive figure for a rotatable physical object, an array for authored token or matrix values, and a flowchart for a requested process diagram.
3. Label the important parts clearly. Ground desktop pointing in current screen observations rather than guessed coordinates.
4. Explain one short step at a time, highlighting the part being discussed. Keep the written and spoken explanation in Pace's shared conversation.
5. Reuse the current visual for follow-ups when appropriate. Let the user rotate, select parts, pause and explore without fighting their controls.
6. Honor close, stop and cancellation immediately. Do not restart narration or reopen a dismissed visual from a late result.

## Notes

Use the selected consented model for reasoning and the selected voice for narration. Do not represent conceptual models as exact CAD or a raster image as a rotatable model. Report unsupported geometry or missing screen permission precisely.
