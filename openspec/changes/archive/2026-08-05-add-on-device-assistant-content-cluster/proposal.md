# Why

Pace has a strong product and detailed internal documentation, but its public surface does not own the search questions that best match its shipped differentiation: on-device assistance, screen awareness, private voice, approved actions, and local meeting notes.

# What changes

- Add five public education pages around those durable jobs.
- Add a reusable Read-mode layout that preserves Pace's existing visual language.
- Register every route in `public-surfaces.ts` so sitemap, API, and Markdown stay aligned.
- Add contextual links from existing home, privacy, FAQ, comparison, and download surfaces.

# Out of scope

- Native app behavior, permissions, pricing, comparison claims, model changes, new dependencies, or release automation.

# Impact

Only the Astro website and its public-surface registry change. Existing routes, anchors, navigation labels, consent language, analytics identifiers, and native code remain stable.
